## 场景与直接断言

[固定业务夹具](../tests/fixtures/m6_business_acceptance.json)事先编排 158 个合成对话，逐条保存完整原子要求、合成替代说明、所属场景与直接断言。全部 522 条都有同场景证人；条件分支可有多个证人，同一 AT 仍只计一次。场景数量、user 轮次、HTTP 次数、变更发送和 unittest 方法数分别计数。

这些是本地需求验收，不是原始课堂客户策略／完整初始数据库的复现，也不是实际模型或课堂评分。原资料没有给出的订单、价格、商品库存与客户回复明确使用合成替代；由可信生产器支持的有限自然语言和完整 JSON 驱动默认入口。不能据此声称任意自然语言理解或原始课堂 134/134 通过。机器能执行固定断言，但其是否充分表达原子语义仍须人工评审。

每条原生对话从固定完整后台及可信 context 开始；实际 SDK agent 与 toolkit 接收真实 user 轮次，走原路由、只读调用、完整复述、后次确认、认领、单次写、回执和自有强读回。没有直接注入 confirmed／verified。逐轮精确比较读取与写入 endpoint/body/次数、当轮 code、身份、最终完整后台相对起点的固定补丁及 journal；另外从实际 history 提取 source/basis/operations，供每条 AT 的直接谓词检查。政策拒绝是相应要求的正确结果，不改称写入成功。

[业务验收器](../scripts/business_acceptance.py)拒绝缺场景、缺证人、错原文、错目标、额外读取、额外发送、缺完整复述、无关后台变化及不匹配的来源。纯控制报告不能发布业务证据；只有[原生 worker](../tests/sdk_m6_business_checks.py)实际成功后由[主包装](../tests/test_m6_business.py)设置的观察能进入完整报告。读方重新计算全部 AT 状态与断言，不读手抄通过数。原 M6.1／M6.2 两份固定对话保持不变。

转接摘要使用两种事先固定的 oracle：固定字符串，或 `SOURCE_BOUND_TRANSFER_SUMMARY_V1` 来源关系规则。后者只用于可信 conversation 转接端点，检查实际 user 原文／索引、身份、固定场景要求的订单事实、此前完整业务操作及状态、已完成／未决划分、实际任务与诊断、无 pending 及 settlement=false；通过后才归一化该字段供原轨迹比较。实际原始摘要仍保存在报告，不用其自身输出生成期望。该规则和哈希都不是历史签名，也不证明宿主提供的整段历史真实。

本批修改 13 个既有生产文件，没有新增 agent 文件、工具、schema 或后台字段；仍为 schema 12、八 READ＋七个内部 WRITE。

- delivered 换货可由可信动作启用同规格替换；pending 修改仍拒绝无变化。同款目标也须校验同产品／库存／次数，并按原成交价与当前目标价复核差价。

- 客户可用有限完整命令估计指定原单位，或比较同单退货与换货的节省。新鲜自有订单／目录读取、选项筛选及完整配对复用已有规则；并列仍要求选择。同单互斥明确展示；分析不建提案、确认、任务或写许可，后续选择必须走新的完整业务请求。
- 商品完整 JSON 可包含 `max_total_price`：按全部原单位及所选目标当前价精确计算整单目标总额，包括不修改的单位和重复次数；超限在提案／发送前拒绝。预算和原文来源绑定、恢复重算、写前刷新；不替代公开有符号差价算法，不进入 API body。
- 每个替换对展示原／新价格及有符号分项；完整差价仍按请求顺序 float 累加、最后 round(total,2)，不加总已舍入分项。

- 有限退货资格询问只准备和解释，不把问句当同意。邮箱修改、新方式创建、拆付、代下单、恢复取消、赔偿／补发、五天保证等不支持能力如实解释，不虚构 API、已退款或安排。

## 保留的具体边界

当前仍是单一可用提案集合，明确逐单澄清与新完整确认；没有自动拆分任意组合自然语言的调度器。完整复述超过 4,096 字符拒绝并建议人工协助，不截断或拆清单发送；读、参数、结果和模型投影仍受已有预算限制。

退款预计额保留原价精确合计及 half-up 显示标签，线上不发送金额；取消逐原 charge，换货只记录申请；预计额、可见交易、实际到账不合并。原始课堂响应／真实模型效果、支付网关事务与到账未实测，属于 M7 的具体观察范围。多对换货若上游独立排序造成配错，或回执出现未经约定的字段，仍按 Unknown／人工核查处理；后台可能已产生效果，不重发或自动补偿。

单次发送保证仍限同一共享内存认领表；进程崩溃／新空表配丢失 sent 的旧 state 不具备跨进程去重保证。整体历史真实性和外部 SDK／宿主日志的所有行为也不由本地工件证明。这些边界不登记为等待额外平台算法的工程前置，不用本地合成结果替代真实远程事实。
