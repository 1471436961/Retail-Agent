## 核查方法与环境可见性

以下事项不是新的业务缺口，也不是等待平台提供算法的开发前置。

- `.venv` 默认会被 `rg` 忽略规则排除；显式读取已知文件，或用 `rg --no-ignore --hidden` 检索指定目录。零命中不能直接当作模块／行为不存在；还须区分包目录与 `.py` 模块、信封与条目、前置守卫及上下文作用域。
- 2026-10-07 实施工作区 `E:/Retail-Agent/.git` 实际存在。评审导出工作区可能看不到 `.git`，因此把此项记录为评审可见性限制，不写成仓库没有版本控制。仍保留 [历史基准](../tests/fixtures/m6_3_source_baseline.json)、[显式变更清单](../tests/fixtures/m6_business_changes.json)和当前逐文件哈希，便于不依赖 Git 的独立核验。
- `.venv/installed-packages.txt` 记录 `tau2 @ file:///E:/Retail-Agent/.venv/tau2-source-6e9f34c685d4`；安装元数据目录为 `tau2-1.0.1.dist-info`。固定源码中实际存在 `src/tau2/hyper/client_api/__init__.py`，安装目录中实际存在 `Lib/site-packages/tau2/hyper/client_api/__init__.py`。本次直接文件读取核对两者 SHA-256 均为 `7247acf6f9fd18caa83c23c9114c469cc1231f0a5cde33bf026eb495e0efedc3`。所以“固定源码不含 client_api”不符合本工作区观察，不能列为项目缺失。

上述 SDK 核查只证明这些明确文件存在且该文件字节相同；安装来源字符串或带提交号的目录名不能单独证明整个 SDK 与固定源码一致，更不能证明课堂镜像一致。M7 在实际可观察范围内记录 SDK 版本、模块实际来源、关键依赖文件哈希和课堂提供的镜像信息；缺少信息时写清具体未观察项，不猜测等价，也不把它作为重复等待用户补材料的理由。
