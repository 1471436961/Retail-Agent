## 范围与分类原则

计划要求按规则理解、工具参数、确认流程、对话遗漏、运行时兼容记录根因。本批交付[有限台账](../tests/fixtures/m6_defects.json)及[可执行核查](../scripts/defect_register.py)，收录 15 项有实际修复位置与回归方法的记录。14 项是历轮已修问题，1 项是本轮新发现并修复的证据发布缺口。不是 15 个新增能力，不是历次所有失败的穷举，也不把一个缺陷引发多个失败方法当成多个缺陷。

每项使用一个稳定 ID 和一个主要根因分类，明确区分 production 与 test_infrastructure。生产缺陷不能因为首次由测试发现而改记“测试预期错误”；夹具、审计器或证据发布错误也不冒充业务修复。台账的 root_cause／fix 为人工审阅判断，AST 只能核查引用存在，无法自动证明根因分类正确。当前方法通过不证明旧失败版本已在本轮逐项重新执行。

规则理解包括取消范围不得扩大、未解析条件不得变成规格值，以及精确证据与顾客显示的口径区分；工具参数包括退货元数据／迁移接线、反例必须使用合法候选形状、隔离上传包须核查实际字节；确认流程包括最后补充询问、prepare 与 execute 丢失结果的不对称，以及展示元数据与确认事实的隔离；对话遗漏包括混合动作冲突诊断和跨单 Unknown 的过度全局阻断；运行时兼容包括 SDK 工具发现、墙上创建时间、审计器 compile 区分和报告结果契约。

M5.3 同批诊断／迁移接线遗漏合并为一个元数据接线记录，不按两个失败点计数。纯文档收尾（机制描述、上游文件引用、历史包数字、单一当前状态）保留各批交付记录，不计为生产缺陷。M3.5 D2、SDK 包不存在、F1 的“第 37 个测试”、载荷数字仅存在散文，以及 Path.open／junction 原拒绝不存在等已否证项不列入待修台账。

## 本轮新修复：完整结果与发布计数

修改前用 FoundationTraceTests 的纯合成控制报告验证：所有已引用组仍 passed，额外加入 unreferenced.Case.test_failed=failed 并让 tests_run 等于结果数，build_trace 仍返回 valid；仅虚增 tests_run 100 也返回 valid。两项都未运行真实业务或网络，结果是直接调用原发布验证函数所得，不是静态猜测。

根因是 build_trace 只核查顶层“零失败”声明及引用组，没有核查全部 outcomes 与实际方法总数。正常主 runner 本来会从实际 unittest 生成计数并阻止失败发布，所以这里是报告读取／再发布的完整性缺口，不是生产写入或普通主运行绕过。本批修复为全部结果必须 passed，tests_run 必须为正的严格整数且等于结果字典长度；exit_code／failures／errors／skipped 的零值也必须为严格整数，不能用 bool／float 混淆类型。

专项保留合法报告正向对照，负控分别使未引用方法 failed／error／skipped／unknown、篡改总数、使用 bool／float 零计数，以及在旧 valid 配对上再发布含失败的报告。最后一项必须先废止旧追踪、写入 trace_rejected 报告并保持 invalid，不能仅抛错而让旧 valid 冒充新运行。原缺原生观察负控同步补齐一致方法计数，使其继续触达原生来源门；没有把更早的计数拒绝当成该来源门的证据。

## 闭环证据与哈希范围

台账逐项核查根因／修复非空、ID 和证人集合不重复、五类都有记录、原交付文本锚点存在、修复函数／类与测试类／方法真实存在。发布时另要求每个关联方法在本次完整报告实际 passed，台账／验证器／原交付说明／修复文件／测试文件的当前字节哈希与报告 source_files 一致。带台账的完整源码若缺少台账检查方法，也不能发布其闭环证据。

FOUNDATION-RUN 保存逐方法实际结果和逐文件源哈希；AT-TEST-TRACE 的 defect_closure 由验证器从这些结果、哈希与冻结台账派生，读方重新计算整个对象并比较，不能只改 incident_count 或复制一段成功文案。报告不另存一份手工闭环副本。唯一当前计数来源仍为 [当前证据](CURRENT-EVIDENCE.md)；历史缺陷数、新增修复数、不同回归方法数分别保留，不加到 unittest、对话、HTTP 或完整业务 AT 数。

与此前 source_files 范围相比，本批显式加入 defect_register.py、m6_defects.json、台账测试及其引用的历史交付文档。后者此前不属于整体 source 摘要；现在修改这些选定说明也使当前证据失效。并不声称所有 docs/ 或 materials/ 都被纳入，不扫描凭证，不依赖 .git 来读取这些字节。新台账／脚本／测试在 agent/ 外，不进入部署包。
