## 本批真实修复

案例 18／30／91／107 的同规格故障换货要求暴露了已有实现缺口：`resolve_replacements` 将 pending 商品修改的“无变化”拒绝无条件用于 delivered 换货。固定上游 `tau2-source-6e9f34c685d4/src/tau2/domains/retail/tools.py` 的 `exchange_delivered_order_items`（207–298 行）检查状态、商品归属、次数、库存及已有方式，没有禁止同 ID 换同 ID。该判断来自直接打开固定源码，不来自被忽略目录的检索零命中，也不等待新增课堂资料。

现在只有可信 `exchange` 动作可启用严格布尔内部标志 `allow_same_variant`；它不属于工具参数或用户授权字段。普通 pending 修改仍返回 `unchanged_variant`。有限原文 `same variant`／`same item`／`identical replacement`／同款／相同规格从客户指定的原单位派生同 ID 目标。准备及写前业务复核均检查库存、同产品及选项，并按订单原成交价与目录当前价重算差价，不能猜同款差价必为零。完整复述、后一次真实确认、单次认领、回执及自有强读回仍适用；不解锁第二次换货。

本地固定 `retail/tools.py` SHA-256 为 `9c7bee3e877cfaf9335fe95aefe1846747b6b99a1d3f1e7a202068b6435bd204`。本批另通过 Parallight Lab 的 enterprise-ai／retail_plus 只读公开资料查询询问完整初始数据库／客户策略的获取路径及同款禁令：返回 `integrations/enterprise-ai-starters/common/INTERFACE-CLARIFICATIONS.md`，version `d58e1786ae00`（含 U5 次数／同产品／库存／完整确认边界），以及背景 `materials/uploaded_materials/intake_form.md`，version `51dd76b64144`。该次证据包没有给出完整 134 案例 fixture 或额外同款禁令；其 limitation 明说无隐藏用例、原始响应或完整轨迹。这是“本次未取得”的精确范围，不证明任何后台事实不存在；不把它作为继续实施的前置，也不调用真实写探测或付费模型。

## 直接业务验收与关联分离

新增 [业务验收器](../scripts/business_acceptance.py)、[固定业务夹具](../tests/fixtures/m6_business_acceptance.json)及[原生 SDK worker](../tests/sdk_m6_business_checks.py)。全量 134 案例／522 AT 从原需求严格解析并保留；只有保存完整原子要求、明确替代范围、原生对话及直接断言的条目可计为 `passed_local`。未写场景或未执行的条目是 `not_executed`，不因组件通过、旧对话关联或相近要求而升级。

首批选择案例 107，两份独立起点的场景分别检查同款有库存／同款无库存后客户明确选择 9 码、皮革、防水回退，以及另一本人订单的 1000→500 片拼图、保留 hard 难度、“更 fancy”须澄清后由客户选择 art。每单独立完整复述及后次确认，一次申请；无关订单、原商品及支付历史须与起点一致。固定起点、逐轮精确读写、code、最终补丁沿用原生 oracle；新增逐轮派生 basis 观察，直接断言选项、条件来源、完整载荷与实际结果。

客户原文保留“比原值少 500／更 fancy”，该有限表达先澄清，由客户明确 500 片／art 后进入提案；不声称已实现任意相对数值自然语言解析。原规格 1000 片及最终 500 片／hard 均直接断言。客户看到的两份订单号、完整 ID 对、方式和分别 0.00／15.00 与 2.00 差价也有直接文本断言；负控保持正确后台、basis、code 和 journal，只替换成缺清单／方式／金额的复述，仍须由业务断言拒绝。

该批使用明确标注的合成订单、商品、价格及有限客户回复，**不是原始课堂后台 fixture、任意自然语言效果或真实模型验收**。案例 107 的四条本地要求各有直接断言，计四条，不把两条分支计八条。案例 18／30／91 虽受同款修复影响，本轮未直接执行，仍不得计通过。全量收口仍须逐条完成剩余场景与断言；现有语言／组合调度缺口是实施工作，不笼统登记为等待平台。

`FOUNDATION-RUN.business_batch` 保存实际观察，`AT-TEST-TRACE.local_business_acceptance` 从冻结夹具及本轮观察重算完整 522 条状态、断言及替代说明。主 runner 要求原生包装实际通过，绑定同一 run/source 与输入字节；缺观察、错来源、缺场景、错误目标、额外读取或无关后台变动均拒绝发布。增加一个手工“已通过”计数不能替代观察。元数据及哈希不是签名；人工原子语义映射仍需评审，机器只核验已固定的断言，不能自动证明断言充分覆盖任意自然语言含义。
