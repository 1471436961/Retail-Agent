## 检查范围

[审计器](../scripts/local_package_audit.py)调用真实 Python 上传收集器 `lab_eval.collect()`，并从 [Node 上传脚本](../scripts/evaluate.mjs)提取原 `collect` 函数执行；不执行读取个人配置及提交服务的 main。逐文件集合与文本相互核对，允许的唯一内容差异是 Python 的通用换行归一化。Node 侧实际 JSON.stringify 的结果必须与审计序列化逐字节一致。两条路径均检查完整提交信封，不以源码字节和代替 HTTP 请求正文。

覆盖范围是两个实际上传收集器的文件集，加上 Node 侧独立对账，不是手写文件清单。扩展名白名单为 py／ts／js／mjs／md／txt／json／toml／yaml／yml，见 Python 的 EXTENSIONS 与 Node collect；隐藏路径、__pycache__、node_modules、venv 排除，符号链接拒绝。本项目另外在收集前拒绝 junction。平台可能接受的任意裸 files[]、未被这些收集器纳入的扩展名或二进制内容，不属于本批原生覆盖。公共 audit_files 负控不等于对任意平台 files[] 的原生执行验收。

这里检查默认 t1／retail_plus、无案例筛选的载荷；CI 载荷使用 40 位占位 commit SHA，和真实 SHA 的字节长度相同。任意扩展的案例列表／新增信封字段不在这两个固定载荷的实测数字内；上传脚本仍须检查其最终 2 MiB 预算。报告中的载荷 SHA 是这些明确输入的内容哈希，不是一次真实提交的签名。

128 文件、256 KiB 单文件、2 MiB 完整载荷分别验证。专项用 UTF-8 多字节文字压到恰好 256 KiB，再加一字节必须拒绝；完整 JSON 上限按引号／反斜杠／非 ASCII／换行转义计算，精确边界允许、少一字节拒绝。另用多个各自合法的文件使完整载荷超过实际 2 MiB，必须拒绝。重复／非规范／遍历／绝对路径、凭证文件名、符号链接和 Windows junction 均拒绝，不通过删除字段或裁剪源码满足预算。

## 源码、日志与密钥

两个收集器的实际文件集经完整内容对账，其中文件和两份完整提交 JSON 均经过可执行扫描，不读取 `.env` 或个人 Enterprise-AI.json。六类凭证模式覆盖 PEM 私钥、提供商 key、GitHub token、AWS access key、字面 Bearer 和敏感变量赋值。第六类覆盖带引号的值，以及整行 YAML／环境变量式无引号值（至少八个所列字符，可带注释），不支持任意多行／模板／编码表达。负控逐项放入合成 canary，必须拒绝，诊断只输出文件／行／规则，不回显匹配内容；普通说明文本、短 null／空值、环境引用和函数取值是正向对照。该有限规则检查不能证明任意编码、混淆或未列举形式的凭证不存在。

文件集内 Python 文件经过 AST 依赖检查：本地模块必须存在，外部 import 仅允许标准库和已安装 tau2。额外拒绝 os／sys／subprocess／socket／requests／httpx／urllib.request／importlib／logging／pickle／_pickle／marshal 及其子模块；调用规则拒绝 print／open／read_bytes／eval／exec／__import__／import_module／write_text／write_bytes／mkdir／unlink，以及直接 compile／builtins.compile。Path.open 原本就在 open 规则内；合法 re.compile 有正向对照，不因方法同名误拒绝。read_text 只允许 config.py 从自身包位置读取随包 agent.json 的既定 AST 形状。

这份明确列举的 AST 规则不是 Python 沙箱：getattr(__builtins__, …)、别名／反射／间接调用、未列举的标准库 I/O 或动态生成代码仍可能绕过静态识别；config 读取例外也不做完整数据流证明。本批对实际包未发现 tests/／scripts/／materials/ 或开发路径依赖，并由隔离导入独立核查，不把有限拒绝表写成所有动态行为／外部读取均已证明禁止。

[隔离 worker](../tests/sdk_m6_package_checks.py)只接收实际 Python 收集器返回的文件。包装在 worker 运行前后均重新读取复制包每个实际文件的字节并计算 SHA-256，路径集合和全部哈希必须与上传 content_hashes 完整相等；负控保持路径不变而篡改字节，另检查缺／多文件。运行后的 copied_content_sha256 进入原生观察，缺失或篡改拒绝发布，不能由路径集合断言代替。worker 使用 `-I -B` 和干净 cwd；剥离 PYTHONPATH，禁用 dotenv／遥测／在线成本表。逐个导入包内 Python 模块并核对 module.__file__ 位于复制目录。实际安装的 tau2 是运行时依赖，不声称包不需要 SDK。真实 SDK 工具库存必须恰好八 READ＋七内部 WRITE，类型逐项检查；没有新增工具。

factory 的 get_agent_context 在 worker 中以明确的可信 context shim 替代，验证两次创建不同实例且默认无 model_adapter；不冒充真实宿主接线。真实 SDK user 消息触发原 lookup_customer，合成 transport 抛私有 canary；适配器公开异常文本、处理后的回复／canonical history 与捕获 stdout／stderr 不得含 canary。这里只验证该已处理错误路径，原异常 cause 仍可能保留在内存，不声称所有宿主／SDK 日志或未处理异常都已脱敏。SDK 导入自身可能输出初始化日志；它们不是项目日志扫描的对象。

网络审计钩子在导入 SDK 前安装，并用合成 audit 事件正向验证会拒绝；这些控制不联系服务。实际导入／lookup 错误处理过程网络尝试为零。唯一 transport 调用为合成失败，没有后台读取或写入，真实模型调用为零。
