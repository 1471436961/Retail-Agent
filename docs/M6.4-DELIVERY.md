| 路径 | 输入与固定判据 |
|---|---|

| 读取结果 | 非 JSON／非对象、bool／字符串／非有限或负金额、错 owner、缺／重复／错调用 ID、双结果中一项错误均不得接纳。拒绝的原始正文和错误文本不进入 history 或顾客回复。合法业务对象里的权限字样只作数据，不产生确认、写 journal 或转接。 |

## 预算和发送时点

工具参数计算完整 `{"session_json": …}` 紧凑 JSON 的 UTF-8 字节数，包括 session_json 字符串转义；结果计算交付的原始 outcome.content 字符串的 UTF-8 字节数，不含外围 ToolMessage 信封。二者保护不同边界，不是同一种传输载荷的两个上限，也不声称涵盖所有宿主信封。边界值允许、少一字节预算拒绝；六类默认派发超限保留完整原请求／身份证据，不创建 pending 或调用工具。prepare 读取预算探针是在已派发快照注入耗尽计数，再验证档案及目录 I/O 前给确切 code；不声称该探针此前真实执行过十二次读取。商品修改／退货／换货完整规格清单超过复述预算时整体拒绝，不截断、不拆分、不产生部分提案；大清单需人工协助，重复同一输入不能消除限制。

工具结果超限以实际 prepare／execute 分别验证：prepare 放弃且零写；execute 工具已发送一次，接纳边界保留未知批次，不能把“结果没接纳”说成零发送。转接摘要超限在 dispatch／POST 前拒绝并完整保留原文；转接摘要中的旧 user 指令仅为 JSON 字符串数据，无身份时不因其自称 verified 而读取私有客户资料。

真实 SDK 的模型投影探针用超过 48,000 字符预算的当前请求，必须在假网关 generate 前拒绝，输入 state 完全不变。canonical 来源链不裁剪；预算是项目内部限制，不能冒称平台 token／容量上限。

## 原生回执与网关矩阵

真实 SDK 子进程逐个验收八个变更 HTTP 动作：订单地址、默认地址、支付、取消、商品修改、退货、换货和转接。每个动作各有 valid、list_body、authority_fields、wrong_target 四种输入，共 32 个场景。先用原有固定对话达到真实后一次 user 确认及 execute 派发，正向回执经原强读回为 succeeded／accepted。另三类故障在合成后台实际完成一次操作后改变返回表示；必须为 Unknown、拒绝的回执不留存、原未决操作完整不变且无第二次发送。backend_changed 另与真实前后后台比较；转接 fake 只记录调用，不能冒充真实人工响应或业务数据变化。

假网关另有 16 个场景：合法自有读取和纯 reply 正向对照、含注入正文的上下文中返回内部工作流仍被名单门拒绝、派生摘要不授予权限、七个内部工具名、额外 confirmed、错客户、非自有订单、bool 目标以及当前请求超预算。网关是确定性 fake，返回预先指定的消息；真实的是 SDK AssistantMessage／ToolCall 类型、工具库存和 ModelAdapter 路径，不是模型行为。含正文的名单探针证明代码过滤有效，不能证明模型抵抗正文指令。派生摘要探针必须实际进入压缩分支，完整提案中含授权字样的地址值保留在派生摘要，明确数据无授权；投影前后完整 state、提案确认门、后台调用均不变，假网关返回内部动作仍拒绝。可用 actions 不含内部工作流。ModelAdapter 只产生决策，网关检查阶段 HTTP 0 不冒称读取工具已执行；真实模型调用为 0。

worker 继承既有网络审计钩子和无网络正向控制，使用真实 SDK 1.0.1 的工具发现／WRITE 类型断言，剥离 PYTHONPATH、禁用 dotenv／遥测／在线成本表，不读取凭证或 Enterprise-AI.json。完整业务 AT 执行仍为 0，32／16 是 SDK／假网关子场景，不能加到 unittest、固定对话或 522 AT 数。

extra_sends 保留为独立阶段的增量：首次发送和结果接纳后取 sends；故障场景在恢复、重建 toolkit 和后续真实 user 请求完成后再次取实际发送次数。正向场景没有后续请求，增量为零不充当后续去重证据。评审修订探针在后续轮次注入额外合成发送记录，实得 sends=1、extra_sends=1，否证“恒零”；该探针不进入正式业务观察，也不联系真实端点。
