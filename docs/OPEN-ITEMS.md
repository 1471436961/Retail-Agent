## 接口职责与状态口径

面向 Agent 的工具名称、参数、说明和返回结构，以及内部候选动作、任务、提案、确认和提示词，由本项目设计。平台规定工厂、轮次消息、Client API 和模型网关的集成方式；评测器调用我们的实现，不会替实现补齐模型调用或业务逻辑。

Python 网关的 `generate()` 签名、消息/工具对象、返回值及主要用量字段已经公开；TypeScript 对照也已取得。内部模型接口、候选与 fake 由项目设计，薄适配层按已知契约转换并验证真实 SDK。可选参数细节、异常类型和实际环境兼容仍待核实，检查接口不等于执行收费模型调用。JSON-only state 是本项目工程约束，平台契约将其定义为不透明状态对象。
