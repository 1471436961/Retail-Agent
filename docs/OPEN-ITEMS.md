## 接口职责与状态口径

面向 Agent 的工具名称、参数、说明和返回结构，以及内部候选动作、任务、提案、确认和提示词，由本项目设计。平台规定工厂、轮次消息、Client API 和模型网关的集成方式；评测器调用我们的实现，不会替实现补齐模型调用或业务逻辑。

内部模型适配接口与 fake 可以先实现。Python 网关的方法名、签名和返回字段在薄适配层联调，不作为 M2 或整个业务开发的前置阻塞。若获得官方 TypeScript 示例，可参考其语义和流程，再核对 Python 调用方式；取得 TypeScript 版本不是开发前提。检查 SDK 签名与执行收费模型调用是两件事。
