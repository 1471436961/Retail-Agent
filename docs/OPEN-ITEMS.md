## M4.1 的边界与后续承接

地址输入支持明确目标、字段标签、地址 JSON、五/六段完整地址及自有档案/订单复制；不声称识别任意口语。教学订单没有日期，不能从“最近订单”猜目标。初始条件或先后序列必须澄清；条件确认、撤回、改字段、事实变化不能支出旧同意。新展示仍沿用一份完整可用集合的规则，跨订单保留须显式纳入集合；没有独立多展示上下文。

address_pending 由原 history 的 dispatch/result/unknown/abandoned 重建，完整批次才接纳后继 state。只读 prepare 丢失/错误/拒绝或实际 user 插入下一轮时可安全 abandoned，重新准备或继续其他请求；迟到结果不能覆盖新 prefix。execute 丢失仍可能已写入，保留 unresolved reservation，不自动重发。两类 PUT 不具有跨记录原子性；第二项异常时保留已返回的第一项成功 journal，未返回的私有 journal 不能冒充可见结果。该限制不是新的外部等待项，不发明状态查询端点。

内部工具参数/结果预算已实现为 256 KiB/1 MiB 的序列化 UTF-8 字节，并在调度、工具解析和结果接纳边界检查。超限保留完整身份、同意和 journal；prepare 返回可恢复短诊断，execute 交付不全保持 Unknown。intake/prepare/execute 现在都有结构化 code 和逐记录诊断，write_authorized=false。WRITE 注册属于固定 SDK 支持的工具类型；模型仍只有八 READ，当前默认工厂不安装真实模型，也没有需要新增的 agent.json 工具权限清单。

地址 toolkit 默认拥有一份进程内 SessionClaims；同一个 live 后端重建 toolkit 可显式注入同一可信 store。不同重放后端使用独立 store。新空 store 配已丢失发送证据的旧 state 仍不保证跨进程去重，不新增 CAS/签名作为实现前置。执行只接受当前已确认的完整地址项；Unknown 订单不阻断另一自有订单，后台地址相同不冒充 Unknown 本次成功。

## M4.4 / M4.5 当前边界

转接不要求私有身份读取；摘要如实区分核实/未核实、完成/Unknown 和阻塞，不把用户文本当命令。投诉/辱骂不自动转接，条件或混合请求先澄清。业务 execute 结果丢失时保留 Unknown reservation，可明确请求人工调查；受理或转接自身 Unknown 后停止所有默认业务/模型派发。明确 rejected 不构成转接，新的显式 user 请求才可再试，业务可继续。

原 handoff 槽在 schema 9 与事件闭合验证，自报 accepted/transfer_id 拒绝；真实 v8 fixture 迁移不创造受理。新工具实例共享 SessionClaims 可拦陈旧快照，转接不确定/受理也阻断旧业务工具的前置刷新；不同可信会话隔离。新空表、丢失 journal、外部整体伪造历史、并发在途操作及跨进程崩溃不在保证内，M7 必须如实报告。转接受理不证明人工已响应，支付/退款记录不证明原子事务或到账；不把这些变成等待未知平台资料的开发前置。

评审收尾：转接保留 WRITE 并显式 mutates_state=True，契约的 GENERIC 示例不构成强制标签或开发阻塞。本库额外拒绝纯空白 transfer_id。摘要内嵌文字的数据隔离与 Unknown 不升级已补测试，但不能外推下游模型免疫。canonical 恢复无 API 与 SDK Environment 评测重建分开验收：后者执行工具，须隔离 fake 后端及独立 claims；对原 live claims 重放陈旧 dispatch 不再 POST，并因返回 Unknown 被严格回执比较拒绝。详见 [M4.4](M4.4-DELIVERY.md)，不靠分类标签假定跳过重放。

## M5.1 候选入口与承接

本批单个原商品候选的结构化筛选及内部应用入口已实现，见 [M5.1 交付](M5.1-DELIVERY.md)。真实 user 索引是条件来源，已接纳完整 get_product 是枚举来源，最新失败不回退旧事实；偏好/回退/目标优先级均显式，不当授权。M5.2 已由默认完整清单生产器调用纯筛选器并接入澄清/提案，M5.3/M5.4 接入退换生产器。这是实施承接，不是等待平台补充选择算法。

M5.2 已确定由可信生产器解析自然语言并复用纯筛选器，不要求客户写 JSON；派生条件保留实际 user 索引与原文，歧义澄清，完整复述包含采纳条件和选用回退分支，不伪造 user 历史。上述约定已在 M5.2 实现：items_basis 按原 user 和已接纳读取前缀重算，schema 10 控制 slot 和旧版本拒绝新元数据；完整清单/最后询问/后一次完整确认、提交前完整目录及唯一性重核已接默认轮次。当前有限单订单 producer 不具备任意自然语言或多订单独立确认上下文；退货/换货生产器仍待 M5.3/M5.4。详见 [M5.2 交付](M5.2-DELIVERY.md)。

M5.2 评审收尾：统一渲染末尾补充询问并恢复校验；模型门遍历真实工作流名和参数绑定；零差价仅接受无新增行或所选方式单条零退款。紧凑复述不丢条件与来源；4,096 字符是说明 note 限制，超限不给新提案、不截断/拆单，重复同输入不能解决，需人工协助。自然语言同单列表合并，完整 JSON 才重置整个 draft。相关正反例及异常/预算已实跑，见 M5.2 交付；不保留为待平台澄清项。
